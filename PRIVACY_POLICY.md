# Privacy Policy for xClick

Last updated: 2026-10-17

xClick is a browser extension for Chrome and Edge that adds local visual and synthesized sound feedback to supported interactions on X.

## Data Collection
xClick does not collect, transmit, sell, or share personal data with the developer or any third party.

xClick does not:
- collect account credentials
- collect personal profile information
- collect payment information
- collect health information
- collect messages or other private communications
- transmit browsing history or page content to a remote server

## Data Stored Locally
xClick stores only extension preference settings in the browser using `chrome.storage.local`.

These settings may include:
- whether effects are enabled
- whether sound is enabled
- selected visual mode
- selected color theme and its custom palette colors
- selected sound mode
- selected volume level

This information stays on the user's device and is used only to make the extension work as configured.

## Host Access
xClick requests access to `https://x.com/*` and `https://twitter.com/*` so it can detect supported interface elements on those pages and render the extension's local effects when the user interacts with them.

## Remote Code and Network Use
xClick does not use remote code.

xClick does not download remote audio assets or send extension usage data to external servers as part of its core functionality.

## Changes to This Policy
If the extension's data behavior changes in the future, this privacy policy will be updated before those changes are released.
